# Demo design

Audience: an engineer evaluating delivery recovery. Put the run and its observations
on the first screen, with the fixed failure conditions beside them.

- Type: locally served IBM Plex Sans; system monospace only for elapsed time.
- Palette: ink `#172b3a`, muted `#516576`, blue `#2459a6`, canvas `#edf2f7`,
  white `#ffffff`, successful checks `#286346`.
- Layout: a narrow scenario column beside the delivery log; stack on small screens.
- Keep observations empty until measured. Separate the fixed fixture from real results.
- Remove the slogan, decorative numbering and marketing feature sections.

References: [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
and [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines).
These choices follow RelayForge's evaluation workflow.
